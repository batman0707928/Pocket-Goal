💎 Pocket-Goal

Small Savings. Bigger Goals.

A modern, simple and intuitive personal finance dashboard designed to help you track expenses, manage savings goals and take control of your money.

📌 About the Project

Pocket-Goal is a personal finance management application that helps users organize their finances in one place.

Whether you're tracking daily expenses, monitoring your savings or planning financial goals, Pocket-Goal provides a simple interface to manage your financial journey.

The project is designed with a focus on simplicity, usability and responsive design.

✨ Features

- 📊 Smart Dashboard – View your financial overview in one place.
- 💰 Expense Tracking – Record and manage your expenses.
- 🎯 Savings Goals – Set financial goals and monitor your progress.
- 📅 Monthly Budgeting – Plan and monitor monthly spending.
- 📈 Financial Analytics – Understand spending patterns through charts.
- 📱 Responsive Design – Use the application across desktop and mobile devices.
- 💾 Data Persistence – Save your financial information locally.
- 📤 Data Export – Export financial records and backups.

Note: Some features are planned improvements and should only be marked complete once implemented and tested.
